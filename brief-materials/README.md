# Brief Materials

Organized source folder for the INDEPENDENCE PHONE Shopify build.

## Folder Map

- `assets/logo/` - source logo files.
- `assets/product-images/` - extracted or supplied product imagery.
- `assets/reference-images/` - user-supplied reference images and small visual notes.
- `assets/site-images/` - images downloaded from the current live WordPress site.
- `assets/video/` - supplied video/reel assets.
- `documents/` - project documents and SOW files.
- `notes/` - raw and structured client notes.
- `research/competitors/` - competitor URLs and references.
- `research/reddit-voc/` - Reddit buyer research, voice-of-customer snippets, ICP segments, objections, and copy implications.
- `research/shopify-product-page/` - MCP extraction evidence for the current Shopify product page.
- `strategy/` - strategic framing, JTBD, messaging, and project approach notes.
- `template-research/` - Shopify theme research, YAML request brief, visual chooser page, and screenshots.

## Important Git Note

`assets/video/indy-phone-reel-1.mov` is about 105 MB. That is too large for a normal GitHub blob, so this repo has `.gitattributes` configured to store `.mov` files in this folder through Git LFS if the file is committed later.
